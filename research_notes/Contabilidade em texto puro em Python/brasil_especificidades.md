# Especificidades do Brasil para um sistema de contabilidade pessoal em texto puro (Python), 2026

Research date: 2026-09-25. Scope: how a Brazilian individual gets household and investment data into a plain-text-accounting (PTA) tool, which Brazilian formats and tax rules matter, what tooling already exists, and which Brazil-specific features would set a new tool apart.
Conventions: **[VIGENTE 2026]** = rule in force in 2026. **[CAIU/NÃO VIGENTE]** = proposal that lapsed or was never enacted. **[A PARTIR DE …]** = enacted, starts later. "Verified live" = I called the endpoint on 2026-09-25 and it answered as described.

## 1. Open Finance Brasil and aggregators: can an individual pull their own bank data programmatically?

### Takeaway
An individual **cannot** connect to Open Finance Brasil APIs directly, because only institutions authorized by the Banco Central can take part. In practice the route is **Meu Pluggy**: a free, no-expiry, personal-use-only way to get Client ID/Secret API access to your own accounts, cards, bills and investments through Pluggy (limit of 5 active connections, one account holder). Commercial aggregators (Pluggy "Dados" from R$ 2.500/month, Belvo from US$ 1.000/month) cost too much for an individual. Actual Budget has an experimental Pluggy integration, and a wave of 2025-2026 OSS/MCP projects consume Meu Pluggy. I found **no** published Pluggy→beancount/hledger importer.

### Cited Findings
**Open Finance access rules**
- Only financial institutions and other institutions authorized by the Banco Central can take part in Open Finance. Clients (PF and PJ) can only *authorize* sharing between participating institutions. — [Open Finance Brasil – Quem participa](https://openfinancebrasil.org.br/quem-participa/); [Perguntas frequentes](https://openfinancebrasil.org.br/perguntas-frequentes/)
- Direct API access is limited to authorized institutions registered in the Participants Directory, not to individual developers. — [Open Finance Brasil – Modelo de participação](https://openfinancebrasil.org.br/modelo-de-participacao/) (per search summary of the openfinancebrasil.org.br pages)
- A TabNews thread notes that only regulated institutions can join directly. Everyone else has to use an authorized intermediary. — [TabNews – "não consigo pagar o Open Finance"](https://www.tabnews.com.br/GuilhermeVieira/estou-desenvolvendo-um-app-de-financas-pessoais-e-nao-consigo-pagar-o-open-finance-pluggy-r2-5k-mes-belvo-r6k-mes-tecnospeed-r1-5k-de-entrada-r540)
- **Consent duration:** Resolução Conjunta nº 7 (Oct 2023, CMN/BCB) removed the fixed 12-month consent limit. Longer validity can now be agreed, renewal was simplified to a confirmation at the receiving institution, and PF came first with PJ extended in 2024. — [Agência Gov (Oct 2023)](https://agenciagov.ebc.com.br/noticias/202310/bc-simplifica-renovacao-de-consentimentos-no-open-finance-e-amplia-prazo-de-validade-do-compartilhamento); [Finsiders](https://finsidersbrasil.com.br/regulamentacao/bc-acaba-com-limite-de-12-meses-para-compartilhamento-de-dados-no-open-finance/)
- **Investments data ("Open Investment", phase 4):** started around September 2023. The APIs cover Renda Fixa Bancária (CDB etc.), Renda Fixa Crédito, Títulos do Tesouro Direto, Fundos de Investimento and Renda Variável. — [Febraban](https://portal.febraban.org.br/noticia/3995/pt-br); [Open Finance dev area – Investimentos](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/75038738/Informa+es+Gerais+-+DA+Investimentos+-+v1.0.0); [Smartbrain](https://smartbrain.com.br/open-investment/)
- Scale: 154 million active consents and more than 100 million connected customers/accounts as of February 2026 (secondary source, per search summary). — [TI Inside](https://tiinside.com.br/20/06/2025/open-finance-no-brasil-com-o-amadurecimento-da-fase-quatro-o-que-esperar-para-o-futuro/) (figure attributed via search summary. The exact origin of the Feb-2026 number was not confirmed)

**Meu Pluggy (personal use)**
- The page is titled "Meu Pluggy — sua API de Open Finance grátis". It says the service is **free for personal use, with no expiration date**. You connect banks at meu.pluggy.ai, create Client ID/Secret at dashboard.pluggy.ai, and pull balances, statements, cards and investments via API into "your own app, spreadsheet, AI agent or existing tool". — [pluggy.ai/meu-pluggy](https://www.pluggy.ai/meu-pluggy)
- Limits on the same page: **maximum 5 active connections** on the free tier. All connected accounts must belong to the same holder. Data refreshes automatically every 24h. **Commercial, multi-user or monetized use is prohibited**. The dashboard's "15-day trial" warnings apply to commercial accounts. — [pluggy.ai/meu-pluggy](https://www.pluggy.ai/meu-pluggy)
- Pluggy is authorized by the BCB as an ITP (payment initiator), and Meu Pluggy runs on the same infrastructure as paying clients such as Conta Azul, Pierre and Kamino. — [pluggy.ai/meu-pluggy](https://www.pluggy.ai/meu-pluggy)
- The GitHub README (pluggyai/meu-pluggy, about 220 stars, topic "nubank-api") describes the flow: create a developer account (15-day trial), add MeuPluggy as a connector in your app, then authorize via OAuth **once per connected bank** (bank, not bank account). — [github.com/pluggyai/meu-pluggy](https://github.com/pluggyai/meu-pluggy)

**Pluggy data model relevant to PTA**
- Pluggy endpoints: `/accounts`, `/transactions`, `/investments`, `/loans` and `/bills` (credit-card bills). Open Finance connectors use the same data model (Items, Accounts, Transactions…) as direct connectors. — [Pluggy docs – Open Finance connectors](https://docs.pluggy.ai/docs/open-finance-regulated); [pluggyai/agent-skills SKILL.md](https://github.com/pluggyai/agent-skills/blob/main/skills/pluggy-open-finance/SKILL.md)
- **Installments (parcelado):** transactions carry `installmentNumber`, `totalInstallments`, `amount`, `date` and `billId`. `totalAmount` is "**Not returned by Open Finance — direct connectors only**". Some banks post every installment immediately, while others create one per bill closing. "**Open Finance does not return a unique identifier that groups all installments of the same purchase**", so heuristics are needed. Pluggy recommends `transaction/created` / `transaction/updated` webhooks. — [Pluggy docs – Credit Card Installments](https://docs.pluggy.ai/docs/credit-card-installments)
- Card transactions in an open bill come back as `PENDING` with no `billId`. They become `POSTED` with a `billId` once the bill closes or falls due. Open bills are not returned until closed or overdue. — [Pluggy docs – Considerations & FAQ](https://docs.pluggy.ai/docs/considerations-faq)
- **Investment history via regulated Open Finance is 1 year, versus 4 years via direct connectors.** Fully redeemed investments are not returned at first connection, only positions active at that moment. XP regulated connectors lack auto-sync for PF and do not support COE. — [Pluggy docs – Considerations & FAQ](https://docs.pluggy.ai/docs/considerations-faq)
- The Pluggy changelog lists new investment fields (tax exemption, Anbima classification, brokerage note, Tesouro coupon) and credit-card fields (fee type, credit operation type). — [Pluggy changelog](https://docs.pluggy.ai/en/changelog) (per search snippet)
- The PyPI package `pluggy-sdk` 1.0.0.post69 (uploaded 2026-09-19) lists author "Pluggy <hello@pluggy.ai>", but its homepage points to github.com/diraol/pluggy-python and it looks auto-generated (the placeholder repo URL is "GIT_USER_ID/GIT_REPO_ID"). Treat it as semi-official. — [PyPI pluggy-sdk](https://pypi.org/project/pluggy-sdk/)

### Inferences
- For a personal PTA tool, **Meu Pluggy is the only practical "bank sync" path in 2026**. The importer should: (a) pull `/accounts`, `/transactions`, `/bills` and `/investments` with the user's own Client ID/Secret, (b) key dedup on Pluggy transaction IDs, and (c) cope with PENDING→POSTED transitions, late-appearing installments and missing `totalAmount` under Open Finance.
- The 5-connection cap fits a household (e.g., Nubank, Itaú, Inter, XP, BTG). A couple with accounts in two CPFs would need **two Meu Pluggy accounts**, because all connections must share one holder.
- Pluggy changes have broken downstream integrations before (Actual #7342). An importer should isolate the Pluggy client behind an interface and keep file-based import (OFX/CSV/PDF) as a first-class fallback.
- The 1-year investment history limit under Open Finance means the investment ledger's opening balances and cost basis (preço médio) must come from B3/broker files, not from Pluggy.

### Gaps
- I did not verify the Klavi or Celcoin pricing pages, or whether they offer any personal/free tier.
- I did not confirm the exact list of institutions that Meu Pluggy supports in 2026, or whether Meu Pluggy exposes credit-card **bills** for every bank (the page says "cards").
- The exact date of the TabNews pricing thread was not captured. Pluggy's official R$ 2.500 floor is consistent with it.
- I found no public beancount/hledger importer that reads Pluggy (searches for "pluggy beancount/hledger/ledger" returned nothing).

## 2. Export formats from major Brazilian banks and fintechs, and their quirks

### Takeaway
File exports are inconsistent across banks. Traditional banks (BB, Bradesco, Itaú, Santander, Caixa) offer **OFX ("Money 2000")** for current accounts, often only for recent windows (60–90 days). Several digital banks restrict PF exports: C6 offers OFX/CSV **only for PJ**, and Inter removed CSV/OFX export of card bills. **Nubank** is the most importer-friendly: account statement in OFX/PDF (and CSV per third-party parsers) and card bill CSV `date,title,amount`. The quirks that matter most are cp1252-encoded SGML OFX with decimal commas, "Parcela X/Y" suffixes, IOF lines on international purchases (3,5% since Jul 2025), long Pix memos with masked CPF, and internal "Aplicação/Resgate RDB" moves.

### Cited Findings
**Nubank**
- Nubank app (PF and PJ): Conta → "Exportar Extrato" → pick month. The **PDF and OFX** arrive by email, all months since account opening are available, and the statement runs until the previous day. — [NuCommunity – Exporte extratos pelo app](https://comunidade.nubank.com.br/novidades/post/exporte-extratos-diretamente-de-sua-conta-nubank-pelo-app-rbRYnw8qndyPd2S)
- Sources conflict on PF OFX: older help pages (Conta Azul, Contabilizei) say OFX is PJ-only, while the NuCommunity post says the app exports PDF+OFX for PF too. — [Conta Azul help](https://ajuda.contaazul.com/hc/pt-br/articles/360052656371-Integra%C3%A7%C3%A3o-banc%C3%A1ria-via-OFX-como-exportar-extrato-em-OFX-do-Nubank) vs [NuCommunity](https://comunidade.nubank.com.br/novidades/post/exporte-extratos-diretamente-de-sua-conta-nubank-pelo-app-rbRYnw8qndyPd2S)

**OFX encoding/format quirks of Brazilian banks**
- Brazilian OFX 1.x is **SGML without closing tags**. Headers often say `ENCODING:USASCII` together with `CHARSET:1252`, while the bytes are really cp1252, so reading them as UTF-8 raises `UnicodeDecodeError`. Other quirks: **decimal comma** (`<TRNAMT>-250,00`, `1.234,56`), dates without time (`20260702`), timezone suffixes such as `[-3:BRT]`, negatives in parentheses, empty tags, several statements per file, and reissued FITIDs (hence dedup by FITID plus a fingerprint). — [chiarelli-dev/ofx-br (MIT, stdlib-only, Decimal; updated Jul 2026)](https://github.com/chiarelli-dev/ofx-br); [quantix-gestor PR #30 (WIN1252, decimal comma)](https://github.com/quantixaicorp/quantix-gestor/pull/30); [PR #28 (SGML without closing tags)](https://github.com/quantixaicorp/quantix-gestor/pull/28); [odoo-brasil issue #1095 (accents)](https://github.com/Trust-Code/odoo-brasil/issues/1095)
- Python OFX libs: `ofxtools` 1.1.1 (2026-06-12) is maintained. `ofxparse` 0.21 dates from 2021-05. — [PyPI ofxtools](https://pypi.org/project/ofxtools/); [PyPI ofxparse](https://pypi.org/project/ofxparse/)

**IOF on international card purchases**
- **[VIGENTE 2026]** Decreto 12.499/2025 set IOF-Câmbio at **3,5%** for card purchases abroad (credit, debit, prepaid) and cash. After the STF reinstated the decree, collection resumed on 17 Jul 2025 (not retroactive). This replaced the planned phase-down (6,38% up to 2022 → 3,38% in 2025 → zero by 2028 under Lei 14.286/2021). — [PwC – Decreto 12.499/2025](https://www.pwc.com.br/pt/consultoria-tributaria-societaria/thinking-about-taxes/tax-legis/2025/iof-alteracoes-decreto-federal-12499-2025.html); [Rádio Câmara](https://www.camara.leg.br/radio/programas/1182454-aumento-do-iof-para-cartao-internacional-volta-a-valer/); [Wise BR](https://wise.com/br/blog/iof-cartao-internacional)
- A 2026 Nubank bill text also lists "IOF de câmbio de 3,5%" for international withdrawals. — [luizhslima/classificador_faturas_v1 notebook (OCR of a Nubank bill)](https://github.com/luizhslima/classificador_faturas_v1/blob/main/notebooks/analise_ocr_vectordb.ipynb)

### Inferences
- A robust importer set for Brazil needs: (1) a **cp1252/SGML-tolerant OFX parser** with decimal-comma handling, (2) **Nubank CSV** (account plus card, both amount styles), (3) **PDF bill parsers** for banks without CSV (Inter, C6 PF, sometimes Itaú), and (4) generic CSV rules. OFX windows of 60–90 days mean users should export regularly, and dedup must be idempotent.
- The ledger model should treat IOF lines as linked to their parent purchase (same category, or tagged `iof`). "Pagamento recebido" / "Pagamento de fatura" should be transfers between checking and the card liability, never income or expense. `Aplicação/Resgate RDB` should be transfers to an asset account.
- Parsing "Parcela X/Y" should generate or match the future installment postings (a liability schedule). The Brazilian hledger plugin `hledger-installments` (2026) shows demand (see §5).
- Pix memos contain names and partially masked CPFs. An importer can extract the counterparty name for payee rules, but should avoid storing CPF fragments in shared ledgers (LGPD/privacy).

### Gaps
- I did not verify current (2026) official PF export options for Santander, Caixa, BB, BTG, Rico, XP (current account), Mercado Pago PF or PicPay PF on the banks' own help pages. Several findings rely on Reclame Aqui complaints (undated) or third-party guides.
- I did not find an official Nubank page that documents the card CSV export path in 2026, nor a formal spec of the CSV columns.
- The common claim that the brokerage-note PDF password is the first 3 CPF digits appeared only in an ambiguous search snippet and was not verified per broker.

## 3. Investment data: B3 notas de corretagem, Área do Investidor, Tesouro Direto, CVM funds, prices and BCB rates

### Takeaway
The authoritative trade source is the **B3 Área do Investidor** Excel exports ("Movimentação" and "Negociação", plus Posição and Proventos). The **B3 Investor APIs** exist but can only be contracted by institutions and fintechs, not individuals. **Notas de corretagem** (SINACOR PDF) are still needed for fees and IRRF, and **correpy** (Apache-2.0, v0.6.0, June 2024) is the main Python parser. ### Inferences
- A PTA investment pipeline for Brazil could run: **B3 Movimentação/Negociação XLSX** (quantities, trades, corporate events), then **notas de corretagem** (fees, IRRF, day-trade flags) to adjust cost basis, then **Pluggy /investments** (current positions and renda fixa at banks), then prices from COTAHIST/brapi/Yahoo, CVM `VL_QUOTA` for funds, and Tesouro CSV for títulos. BCB SGS supplies CDI/IPCA accrual for CDBs/LCIs and PTAX supplies FX.
- The 10-year window on SGS daily series means a price-fetch utility should page by decade. PTAX is available per day, and the tax rules below specify *compra* versus *venda* depending on the purpose.
- Because correpy is stale (last release 2024) and broker layouts drift (Inter issue), owning or forking a SINACOR parser with a regression test corpus is a real maintenance item.
- All Brazilian data files mix `;` separators, decimal commas, latin-1/cp1252 and DD/MM/YYYY. A shared "BR locale" parsing layer (Decimal-only, never float) is a basic requirement.

## 4. IRPF rules relevant to automated calculation (status as of 2026)

### Takeaway
The core renda-variável rules are **unchanged in 2026**: 15% on normal trades with a R$ 20k/month sales exemption for **stocks only**, 20% day trade, 20% FII capital gains, 15% on ETFs/BDRs with no exemption, and monthly DARF 6015 by the last business day of the following month, with separate loss pools. **MP 1.303/2025 lapsed on 08/10/2025**, so the planned unified 17,5–18% rate, LCI/LCA taxation and FII dividend taxation did **not** happen. The genuinely new 2026 items are: **Lei 15.270/2025** (10% IRRF on dividends above R$ 50k/month per company, the minimum-tax IRPFM for income above R$ 600k/year, a R$ 5k/month exemption), **LC 224/2025** (JCP IRRF up from 15% to **17,5%**), **IN RFB 2.291/2025 DeCripto** (new crypto reporting, monthly from Jul 2026), and the ongoing **Lei 14.754/2023** regime (15% annual on foreign financial investments, including crypto held abroad).

### Cited Findings
**Primary reference**
- Receita Federal "Perguntas e Respostas IRPF 2026" v1.00 (2026-04-23): 745 questions. It covers the 2026 filing (ano-calendário 2025), which ran from **23/03 to 29/05/2026**. — [P&R IRPF 2026 PDF](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf); [Receita news (Apr 2026)](https://www.gov.br/receitafederal/pt-br/assuntos/noticias/2026/abril/receita-federal-publica-201cperguntas-e-respostas-irpf-2026201d-com-orientacoes-atualizadas-aos-contribuintes)
- The pre-filled return (Pré-Preenchida, gov.br Ouro/Prata) pulls data from e-Financeira, eSocial/EFD-Reinf, Dmed, Dimob, Carnê-Leão, DOI, DBF, and **crypto operations reported by Brazilian exchanges (IN 1.888/2019)**, among others (IN RFB 2.312/2026). — [P&R IRPF 2026, q.028–029](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)

**Stocks, day trade, options/futures (B3)** **[VIGENTE 2026]**
- Rates: **20% day trade** and **15%** on spot, forward, options and futures. Withholding "dedo-duro" is **0,005%** on sales (not collected when ≤ R$ 1,00) and is compensable against the monthly tax. — [P&R IRPF 2026, q.706](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- Exemption: gains on **stocks in the spot market** (bolsa or balcão) are exempt when total **sales of that asset class in the month ≤ R$ 20.000**. Gold as a financial asset has a separate R$ 20.000 limit. The exemption **does not** apply to day trade, **ETF (índice de ações) quotas**, stock-fund redemptions, or sales from option exercise or forward settlement. — [P&R IRPF 2026, q.707](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- Day-trade IRRF is 1% on the day's profit, and there is no R$ 20k exemption. — [InfoMoney (post-MP 1.303)](https://www.infomoney.com.br/minhas-financas/mp-1-303-cai-no-congresso-veja-como-fica-a-tributacao-dos-investimentos-agora/); [P&R IRPF 2026, q.682 reference](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- **Loss carryforward:** losses in spot, options, futures and forward markets offset gains in the same or later months across those modalities. **Day-trade losses only offset day-trade gains, and normal losses only normal gains.** A loss cannot offset gains of *earlier* months. A December loss can be used in any later month or year but must be reported in the Demonstrativo de Renda Variável. — [P&R IRPF 2026, q.709–711](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- **Payment:** tax is due by the **last business day of the month after the gain**, via **DARF code 6015**. Monthly gains are taxed separately and do not enter the annual adjustment. — [P&R IRPF 2026, q.730–731](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- The **Demonstrativo de Apuração de Ganhos – Renda Variável** is mandatory for sales of stocks on the spot market, gold, forward/options/futures and OTC futures. Holders of only exempt operations may skip it *unless they want to carry losses forward*. — [P&R IRPF 2026, q.729](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- **Average cost (custo médio)** is the method throughout. For example, for covered call writers the cost is "o custo médio de aquisição do ativo conforme estabelecido para o mercado à vista". — [P&R IRPF 2026, q. on options (≈p.330)](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- **DARF minimum is R$ 10,00:** amounts below that are carried to the following month(s) until the total reaches R$ 10, then paid under the latest period. DARFs are issued via **Sicalc Web** (code 6015 for PF). — [Bora Investir (B3) – como gerar DARF](https://borainvestir.b3.com.br/objetivos-financeiros/como-gerar-o-darf-com-codigo-de-barras/); [Sicalc – ajuda](https://sicalc.receita.fazenda.gov.br/sicalc/ajuda)

**FIIs / Fiagro** **[VIGENTE 2026]**
- FII capital gains are taxed at **20%** (Lei 8.668/1993, art. 18). — [P&R IRPF 2026 (FII 20%)](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- FII/Fiagro **distributions are exempt** for PF when quotas trade exclusively on an exchange or organized OTC market. Lei 14.754/2023 tightened the conditions: the fund must have **≥ 100 cotistas** (up from 50), and there is no exemption for a group of related cotistas holding ≥ 30% of quotas or entitled to > 30% of income. The per-holder 10% rule also applies. — [P&R IRPF 2026, q. on exempt income (VII)](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf); [Lei 14.754/2023, art. 41 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2023-2026/2023/lei/l14754.htm); [Renova Invest](https://renovainvest.com.br/blog/fundos-imobiliarios-imposto-de-renda/)
- Conflict: InfoMoney's post-MP article still says "50+ shareholders". That is outdated, since Lei 14.754 raised the threshold to 100. — [InfoMoney](https://www.infomoney.com.br/minhas-financas/mp-1-303-cai-no-congresso-veja-como-fica-a-tributacao-dos-investimentos-agora/) vs [Lei 14.754 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2023-2026/2023/lei/l14754.htm)

**ETFs, BDRs** **[VIGENTE 2026]**
- Equity ETFs: 15% on normal trades and 20% on day trade, with **no R$ 20k exemption**. — [P&R IRPF 2026, q.707](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf); [Renova Invest – ETF](https://renovainvest.com.br/blog/tributacao-etf/)
- BDRs: gains are taxed at 15% with no R$ 20k exemption. **BDR dividends** count as income from abroad under the progressive table, paid monthly via **Carnê-Leão (DARF 0190)** by the last business day of the following month. — [InfoMoney – BDR no IR 2026](https://www.infomoney.com.br/guias/bdr-imposto-de-renda-ir/); [Renova Invest – BDR](https://renovainvest.com.br/blog/tributacao-bdr/)
- **Unreliable source flagged:** one accounting blog (updated 25/03/2026) claims equity ETFs moved to "17,5% in 2026" and that JCP went to 20% under Lei 15.270. This contradicts the lapse of MP 1.303 and the actual JCP change (17,5% via LC 224). Do not use it. — [rolmyjuncontabilidade (unreliable)](https://rolmyjuncontabilidade.com.br/investimentos/ganho-de-capital-acoes-etf-aliquota-2026/)
- A secondary source's figures for the monthly progressive table (exemption up to R$ 1.903,98) are **outdated** and should not be hard-coded. The table changed in 2025 and again with Lei 15.270 for 2026. — [InfoMoney – BDR](https://www.infomoney.com.br/guias/bdr-imposto-de-renda-ir/) (search summary) vs [Mayer Brown on Lei 15.270](https://www.mayerbrown.com/pt/insights/publications/2025/12/enactment-of-law-no-15270-2025-which-establishes-dividend-taxation-expands-the-exemption-threshold-and-introduces-a-minimum-tax-on-high-incomes)

**Fixed income and funds** **[VIGENTE 2026]**
- Regressive table (withheld at source): **22,5%** (≤180 days), **20%** (181–360), **17,5%** (361–720), **15%** (>720). LCI/LCA, CRI/CRA, incentivized debentures (Lei 12.431) and poupança stay exempt for PF. — [P&R IRPF 2026 (regressive table)](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf); [InfoMoney](https://www.infomoney.com.br/minhas-financas/mp-1-303-cai-no-congresso-veja-como-fica-a-tributacao-dos-investimentos-agora/)
- **Come-cotas:** IRRF on fund income is taken on the **last business day of May and November**, or at distribution/amortization/redemption if earlier (Lei 14.754/2023, art. 17). The rate is 15% for long-term funds and 20% for short-term funds, collected by reducing the number of quotas. — [Lei 14.754/2023, art. 17 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2023-2026/2023/lei/l14754.htm); [InfoMoney – come-cotas](https://www.infomoney.com.br/guias/come-cotas/)
- Lei 14.754 also brought closed-end and exclusive funds into periodic taxation from 2024. "Entidades de investimento" such as FIPs, FIDCs, FIAs, FIIs, Fiagros, ETFs and Lei 12.431 funds are exempt from come-cotas and taxed at distribution or redemption. — [Renova Invest summary of Lei 14.754](https://renovainvest.com.br/blog/fundos-imobiliarios-imposto-de-renda/) (per search summary); [Demarest client alert (Dec 2023)](https://www.demarest.com.br/wp-content/uploads/2023/12/DEMAREST_Client-Alert_13-12-2023_Tributacao_de_ativos_no_exterior_e_fundos_de_investimento_v2.pdf)

**JCP and dividends** **[NEW, VIGENTE desde 01/01/2026]**
- **LC 224/2025** (published 26/12/2025) raised the **IRRF on JCP from 15% to 17,5%** for payments or credits from **01/01/2026**. — [Souto Correa](https://www.soutocorrea.com.br/client-alerts/lei-complementar-n-224-2025-cortes-em-beneficios-fiscais-e-novas-regras-para-fintechs-bets-e-jcp/); [Pinheiro Guimarães](https://pinheiroguimaraes.com.br/publicacoes/sancionada-lei-complementar-que-reduz-incentivos-e-beneficios-tributarios-federais-eleva-o-irrf-sobre-jcp-e-aumenta-aliquota-da-csll/); [Demarest alert (PDF)](https://www.demarest.com.br/wp-content/uploads/2026/01/Client-Alert-LEI-COMPLEMENTAR-No-224-2025.pdf)
- **Lei 15.270/2025** (26/11/2025): from **Jan 2026**, dividends paid by one company to one resident PF **above R$ 50.000 in a month** carry **10% IRRF on the full amount**, with no deductions. Transition: dividends from profits up to 2025 approved by 31/12/2025 stay exempt if paid per the original approval, by 2028. — [Lei 15.270/2025 (Câmara)](https://www2.camara.leg.br/legin/fed/lei/2025/lei-15270-26-novembro-2025-798354-publicacaooriginal-177117-pl.html); [Mayer Brown](https://www.mayerbrown.com/pt/insights/publications/2025/12/enactment-of-law-no-15270-2025-which-establishes-dividend-taxation-expands-the-exemption-threshold-and-introduces-a-minimum-tax-on-high-incomes); [Receita P&R lucros e dividendos (Dec 2025)](https://www.gov.br/receitafederal/pt-br/assuntos/noticias/2025/dezembro/receita-federal-lanca-perguntas-e-respostas-sobre-tributacao-de-altas-rendas-consideracoes-sobre-lucros-e-dividendos/manual_padrao_rfb_per_tributacao_sutri_v2.pdf)
- **IRPFM (minimum tax on high income)** **[A PARTIR DO ano-calendário 2026 → declaração 2027]**: applies when total annual income (taxable + exempt + exclusive) exceeds **R$ 600k**, with a rate rising from 0% to 10% and a flat 10% at ≥ R$ 1,2M. Excluded from the base: poupança, LCI/LCA/CRI/CRA, exempt FII/Fiagro income, CDA/WA/CDCA/CPR, LH/LIG/LCD, inheritances and donations. **Stock-exchange gains ARE included**. Taxes already paid are credited, with a cap mechanism tied to the company's effective rate (34%/40%/45%). — [Mayer Brown](https://www.mayerbrown.com/pt/insights/publications/2025/12/enactment-of-law-no-15270-2025-which-establishes-dividend-taxation-expands-the-exemption-threshold-and-introduces-a-minimum-tax-on-high-incomes); [Demarest on Receita P&R](https://www.demarest.com.br/receita-federal-divulga-perguntas-e-respostas-sobre-a-nova-tributacao-de-dividendos-e-altas-rendas/)
- The same law gives an **exemption up to R$ 5.000/month** (R$ 60k/year), with a partial reduction up to R$ 7.350/month (R$ 88.200/year), from 2026. — [Mayer Brown](https://www.mayerbrown.com/pt/insights/publications/2025/12/enactment-of-law-no-15270-2025-which-establishes-dividend-taxation-expands-the-exemption-threshold-and-introduces-a-minimum-tax-on-high-incomes); [Conjur](https://conjur.com.br/2025-dez-04/lei-15-270-2025-dividendos-e-simples-nacional/)

**Crypto** **[VIGENTE 2026]**
- **Held or traded via institutions in Brazil:** rules are unchanged. Gains are exempt if total crypto sales in the month are **≤ R$ 35.000** (counting all crypto types together). Above that, capital gains are taxed at progressive rates (15% to 22,5%) and paid via **DARF code 4600** by the last business day of the following month. Crypto-to-crypto swaps are taxable events valued in BRL at market value. — [P&R IRPF 2026, q.653](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- **Held or traded via institutions abroad (since 01/01/2024):** treated as "aplicações financeiras no exterior" under Lei 14.754 arts. 3–4. Income is declared annually at a **flat 15%**, **with no exemption**, and gains include FX variation on principal. — [P&R IRPF 2026, q.653](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf); [Lei 14.754/2023, art. 3 §1 I (lists "ativos virtuais")](https://www.planalto.gov.br/ccivil_03/_ato2023-2026/2023/lei/l14754.htm)
- Bens e Direitos: crypto goes in **Grupo 08 – Criptoativos** at acquisition cost. — [P&R IRPF 2026 (Bens e Direitos, Grupo 08)](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- Reporting: **IN RFB 2.291/2025 (14/11/2025) creates DeCripto**, aligned with the OECD CARF. It took effect in Jan 2026, with **monthly DeCripto obligations starting July 2026**. The old IN 1.888 model applied until 30/06/2026. PF must report when using foreign exchanges or platforms, or when monthly operations exceed R$ 35.000. Taxation is unchanged. — [Receita news (Nov 2025)](https://www.gov.br/receitafederal/pt-br/assuntos/noticias/2025/novembro/rfb-atualiza-regulamentacao-de-criptoativos-para-adapta-la-ao-padrao-internacional-carf-da-ocde-2013-in-rfb-no-2-291-de-14-de-novembro-de-2025); [Mattos Filho](https://www.mattosfilho.com.br/unico/decripto-receita-federal-ocde/); [Receita – atos DeCripto](https://www.gov.br/receitafederal/pt-br/assuntos/orientacao-tributaria/declaracoes-e-demonstrativos/criptoativos/decripto)
- For crypto reporting conversions, the foreign-currency value goes to USD and then to BRL at the **PTAX closing rate (venda)** for the operation date. — [P&R IRPF 2026 (crypto reporting)](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)

**Offshore investments (Lei 14.754/2023)** **[VIGENTE desde 2024]**
- Income from capital abroad (financial investments and dividends of controlled entities) is declared **separately in the annual return (DAA) at 15%**, with no deductions. Income is recognized when received. Gains, including FX variation on principal, are recognized at redemption, sale, maturity or liquidation (art. 2 §1; art. 3 §2). — [Lei 14.754/2023 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2023-2026/2023/lei/l14754.htm)
- FX variation on **non-remunerated** foreign deposits and debit/credit card balances is not taxed (art. 2 §3). Foreign cash is exempt up to US$ 5.000 of sales per year (art. 2 §4). — [Lei 14.754/2023 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2023-2026/2023/lei/l14754.htm)
- Foreign tax paid can be credited (treaty or reciprocity), converted at the **PTAX compra** closing rate on the payment date, and capped at the Brazilian tax on that income. Unused credit does not carry forward (art. 4). — [Lei 14.754/2023, art. 4 (Planalto)](https://www.planalto.gov.br/ccivil_03/_ato2023-2026/2023/lei/l14754.htm); [P&R IRPF 2026, q.475](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- **Loss offset abroad:** losses offset foreign financial income in the same year, then dividends from controlled entities, then income in **later** years. Each loss can be used once and must be documented. — [P&R IRPF 2026, q.476](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)
- The IRPF program generates a "Demonstrativo de Apuração – Lei nº 14.754/2023" from the Bens e Direitos entries. — [Renault Advogados – DIRPF 2025](https://rplaw.com.br/informativo/informe-tributario-dirpf-2025-investimentos-em-aplicacoes-financeiras-no-exterior/)
- Receita Q&A on offshores (29/04/2024, Lei 14.754 and IN RFB 2.180/2024). — [Ministério da Fazenda P&R offshores](https://www.gov.br/fazenda/pt-br/acesso-a-informacao/perguntas-frequentes/tributacao-offshore/29-4-24-perguntas-e-respostas-offshores-lei-14-754-e-in-rfb-2-180.pdf)

**Asset revaluation (REARP)** **[ENACTED; reflects in DAA 2027]**
- Lei 15.265 (21/11/2025) and IN RFB 2.302 (23/12/2025) created "Rearp – Atualização", which lets taxpayers update the value of assets. It affects only the return for ano-calendário 2026 (exercício 2027). Foreign-currency values convert at PTAX venda for the business day before filing. — [P&R IRPF 2026 (Rearp, q.≈652)](https://www.gov.br/receitafederal/pt-br/centrais-de-conteudo/publicacoes/perguntas-e-respostas/dirpf/p-r-irpf-2026-v1-00-2026-04-23.pdf)

**Proposals that did NOT become law** **[CAIU/NÃO VIGENTE]**
- **MP 1.303/2025** (June 2025) would have set a single 17,5–18% rate on financial investments from 01/01/2026, taxed LCI/LCA (5%, later 7,5% in the rapporteur's text), ended some FII/Fiagro exemptions and changed crypto taxation. The Chamber removed it from the agenda 251–193 and it **lost validity on 08/10/2025**, so the prior rules remain. — [Câmara (Oct 2025)](https://www.camara.leg.br/noticias/1209479-MP-SOBRE-TRIBUTACAO-DE-INVESTIMENTOS-E-RETIRADA-DE-PAUTA-E-PERDE-A-VALIDADE); [InfoMoney](https://www.infomoney.com.br/minhas-financas/mp-1-303-cai-no-congresso-veja-como-fica-a-tributacao-dos-investimentos-agora/); [Congresso – MPV 1303/2025](https://www.congressonacional.leg.br/materias/medidas-provisorias/-/mpv/169059); [Exame (01/10/2025, pre-lapse)](https://exame.com/esferabrasil/tributacao-de-lci-e-lca-avanca-no-congresso-e-pode-redesenhar-mercado-de-renda-fixa/)
- Commentators expected the topic to come back as a bill in 2026. I found no enacted replacement as of Sep 2026. — [Contábeis](https://www.contabeis.com.br/artigos/73399/a-queda-da-mp-1303-2025-o-que-muda-na-tributacao-de-investimentos-e-criptoativos/)

### Inferences
- A tax engine should keep **separate monthly loss pools** (normal: stocks, ETFs, BDRs, options, futures; day trade; FII; and the crypto-domestic ledger), plus an **annual pool for Lei 14.754 offshore** income. Carryforward should be tracked as ledger balances (e.g., `Assets:Tax:Prejuizo:SwingTrade`).
- The R$ 20k test is on **sales volume of stocks only in that month**, not on profit. ETFs, BDRs, FIIs and units need care: units are stock certificates, and I have no primary source confirming their exemption treatment (see Gaps).
- Cost basis must be **custo médio ponderado** including fees from the nota. Fractional-market tickers ("F") merge with their round-lot ticker. Bonus shares, splits, subscriptions and "leilão de fração" come from the B3 Movimentação file.
- New 2026 automation opportunities: (a) track **per-company monthly dividends** against the R$ 50k threshold (10% IRRF); (b) estimate **IRPFM exposure** by summing all income classes, which is only possible in a full ledger; (c) apply the JCP rate by payment date (15% before 2026, 17,5% from 2026); (d) flag DeCripto obligations for foreign-exchange crypto.
- Rates should be stored as **date-effective tables** (e.g., JCP 15%→17,5% on 2026-01-01, IOF 3,38%→3,5% on 2025-07-17), not constants. Brazilian rules change often, and MP-style proposals may be announced and then lapse.

### Gaps
- I did not extract the 2026 monthly progressive IRPF table (bands) from a primary source.
- I did not verify the exact IRPFM rate formula between R$ 600k and R$ 1,2M (said to be linear), or the Receita P&R treatment of B3 exempt gains in the IRPFM base beyond the Mayer Brown summary.
- I did not verify primary-source treatment of **units**, **BDR gains** (15% and whether swing/day-trade split applies), **renda-fixa ETFs** (Lei 13.043/2014 duration-based rates), or **options-exercise** edge cases.
- I did not read the Receita manual for **Bens e Direitos group/code numbers** for stocks, FIIs, ETFs, fixed income and funds (only Grupo 06 for deposits, 05 for credits and 08 for crypto are confirmed above).
- I did not verify whether Sicalc now issues DARFs with a Pix QR code.

## 5. Existing Brazilian tools (commercial and open source) and Brazilian PTA users

### Takeaway
Commercial PF apps (Organizze, Mobills, Minhas Economias) focus on budgeting with Open Finance sync behind paid tiers. Investment trackers (Kinvo, Gorila, Investidor10, Status Invest, myProfit) sync with B3 and some compute IR/DARF. Open source is fragmented: many small Python/TS IR calculators and parsers exist for B3 XLSX and notas, but **there is no maintained Brazilian importer suite for beancount/hledger**. The visible PTA activity is small: an hledger PicPay rules repo, an hledger installments plugin (2026), a Beancount-based app (ledgr), and two Portuguese talks listed on plaintextaccounting.org.

### Inferences
- The commercial market splits budgeting apps (Open Finance, categorization) from investment/tax apps (B3 sync, DARF). No mainstream Brazilian product combines **double-entry household accounting, investments and IRPF in plain text** under user control. That niche is open.
- Brazilian PTA users are few and scattered: rules files, one-off plugins and talks. A curated, tested **"beancount/hledger importers for Brazil"** package would likely become the reference quickly, since the Ukrainian `uabean` set is a precedent for a country-specific importer set ([OSadovy/uabean](https://github.com/OSadovy/uabean)).

- Reddit r/investimentos and TabNews discussions of beancount/hledger were not found by search. I cannot confirm how many Brazilians use PTA.
- I did not open lgili/FinApp to describe its scope beyond the code-search hit.

## 6. Brazil-specific features that would differentiate a new tool (synthesis)

### Takeaway
The strongest differentiators combine the data sources above with rules existing tools handle poorly or in closed form: a **Meu Pluggy sync to plain-text ledger** path, **tolerant BR file importers** (OFX cp1252, Nubank CSV, SINACOR notas, B3 XLSX, PDF bills), a **transparent IRPF engine** (monthly DARF 6015 with loss pools, custo médio, R$ 20k/R$ 35k tests, Lei 14.754 annual, 2026 dividend/JCP/IRPFM rules), and **installment/IOF-aware credit-card modeling**, all with date-effective tax tables and Decimal arithmetic.

### Cited Findings
- No beancount/hledger importer for Pluggy exists (repository search empty), while Pluggy offers free personal API access. — [pluggy.ai/meu-pluggy](https://www.pluggy.ai/meu-pluggy); [GitHub search (no results for pluggy+beancount/hledger)](https://github.com/search?q=pluggy+beancount&type=repositories)
